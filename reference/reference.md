請使用 React、Tailwind CSS 和 lucide-react 圖標庫，為我設計一個完全致敬「Threads 美學風格」的「毛朋友 PawPals Go」雙軌制交友 App 終極高保真互動原型（Pure Frontend UI Prototype）。

這款 App 未來將使用 React Native + NativeWind 實作，請在程式碼中使用標準、可平移的 Tailwind 類名。這是一個純前端 UI 原型，所有數據皆使用元件內部的 `const mockData` 靜態陣列，所有商業邏輯皆透過 React `useState` 在前端進行完美模擬。

---

### 🎨 Threads 視覺風格規範 (Threads Design System)
- **配色**：全黑模式（Dark Mode）。主背景為極致深色（`bg-zinc-950`），卡片與對話框為 `bg-zinc-900`。文字與主圖標為純白（`text-white`），次要文字與線條為細緻的灰色（`text-zinc-500`、`border-zinc-800`）。
- **排版**：移除所有幼稚的卡通元素，改用精緻的細線條（`border-[0.5px] border-zinc-800`）與大面積留白，營造洗鍊的潮流社交感。

### 📱 核心功能與業務邏輯要求 (請在 UI 中完整實作互動)

請在一個全黑的手機外殼（Mobile Frame）內，實作以下三個可切換的純 UI 分頁（Tabs），並整合所有邊界條件：

#### A. 分頁一：身份分流註冊頁 (Welcome)
- **視覺**：中央顯示極簡的「PawPals Go」無限迴圈感標誌。
- **互動**：兩個大膽的純黑/純白對比卡片按鈕：「OWNER（飼主）」與「LOVER（貓狗奴）」，點擊後變更當前身份狀態，並自動淡入滑卡主頁。

#### B. 分頁二：洗鍊感滑卡主頁 (Swipe Deck)
- **相簿切換互動**：卡片預設顯示高質感「毛孩特寫」。點擊卡片的「左半邊」或「右半邊」，可以**實際切換子相簿照片**（1.毛孩特寫、2.主僕街拍合照、3.高冷黑白照）。
- **底部控制鈕**：細線條圖標：❌ (Pass)、❤️ (Like)、⭐ (Super Like)。點擊時卡片要有向左或向右滑開並淡出的 CSS 動畫特效，滑完會自動呈現下一張 mock 貓狗。
- **內購彈窗**：卡片右下角有一個極簡的「投餵肉乾 🥩」按鈕，點擊會彈出一個黑銀配色的高階 IAP 模擬購買純外觀彈窗。

#### C. 分頁三：極簡動態聊天室與終極履約系統 (Chat & Advanced Go! System)
請在此分頁完整實作以下核心商業邏輯的 UI 互動切換：

1. **落實「發起者付費」與預約時間 (Initiator Pays & Scheduling)**：
   - 在模擬聊天室中，提供一個「發起 Go! 約會」按鈕。
   - 點擊後跳出預約彈窗，內建一個極簡細線條的 `[ 選擇未來 7 天內日期與時間 ]` 模擬欄位。
   - 彈窗底部必須強制高亮顯示一條 Threads 灰字提示：`「發起約會將扣除您 5 塊肉乾 🥩 作為誠意金，並暫時由平台託管。距約定時間 2 小時內取消，肉乾將不予退還並直接補償給對方。」`
   - 點擊確認後，畫面上模擬扣除用戶肉乾餘額。

2. **取消與懲罰機制模擬 (Cancel & Penalty Penalty)**：
   - 約會建立後，聊天室上方會顯示一個「進行中的約會」狀態卡片。
   - 卡片中包含一個極簡細邊框的「取消約會」按鈕。為了模擬真實業務，請提供兩個測試按鈕或切換器：
     - *模擬「2小時前取消」*：點擊後跳出提示 `「屬於良性取消，5 塊肉乾已 100% 全額退回您的錢包。」`
     - *模擬「2小時內惡意取消」*：點擊後跳出提示 `「距離約定時間不足 2 小時！5 塊肉乾已被沒收，並作為放鳥補償強制撥給對方。」`

3. **雙向動態 QR Code 簽到（非發起者出示、發起者掃碼）**：
   - 當模擬時間到達約定時間，狀態卡片會變成「線下見面簽到」。
   - **UI 必須完美對稱切換**：
     - 若使用者是「接受約會的人（非發起者）」，卡片中央會產生一個精美的**動態倒數計時 QR Code**（附帶一個 15 秒進度條縮短動畫，模擬 TOTP 時效性）。
     - 若使用者是「發起約會的人」，卡片會顯示一個「開啟相機掃描簽到」純白按鈕，點擊後模擬相機對焦框。
   - 掃描成功後，彈出成功提示：`「驗證成功（PostGIS 空間解鎖過關）！託管的 5 塊肉乾已安全撥入非發起者的錢包 🐾」`。
